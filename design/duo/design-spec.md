# 宛名印刷 はがき・封筒 — iPhone Duo デザイン設計書

> hig-design-skill の手順で作成。対象は **iPhone Duo（外側・内側）だけ**。iPhone・iPad・Mac の画面は既存の設計（`docs/DESIGN.md`、`docs/design/`）のまま。モックは `design/duo/build.py` で生成する（`mocks/` の SVG が原版、PNG はスクリーンショット寸法）。

## 1. 前提

- アプリの目的：住所録から、はがき・封筒の宛名面を郵便番号枠に合わせて縦書き／横書きで印刷する（広告なし・買い切り）
- 主な利用者と利用場面：年賀状・挨拶状をまとめて出す個人。外側の画面では片手で宛先の確認と追加、内側の画面では一覧を見ながら宛名面を大きく確認して印刷
- 対応プラットフォーム（この設計書の範囲）：iPhone Duo の外側（`iphone-duo-outer`、466×678 pt）と内側（`iphone-duo-inner-landscape`、951×669 pt と `iphone-duo-inner`、669×951 pt）
- 画面の向き：iPhone は縦固定（ユーザー指示）。外側の画面はこれに従う。**内側の画面は対応する向きの指定に従わない**（Apple）ので、横向き・縦向きの両方で崩れないようにする
- 判断原則：標準の見た目 ＞ 片手操作（外側） ＞ 情報量（内側）
- 重視する HIG の原則：Familiarity（標準の部品と配置）、Flexibility（開閉・半分折り・Split View で同じ機能）
- UI Kit：未使用（寸法は `references/hig-specs.md` の値と、Xcode 27.1 の iPhone Duo シミュレータでの実測値で描いた）
- 縦の帯の実測値（アプリを Xcode 27.1 シミュレータで撮影）：帯の中心は右端から 48.5 pt。外側のツールバーのボタンは直径 50 pt の丸で、1つ目の中心が上から 198 pt、ボタンの間隔 60 pt（隙間 10 pt）。タブバーは 49 × 164 pt で下端から 23 pt。カメラとステータスバーはシステムが描き撮影に写らないので近似（ステータスバーとボタンの間は 16 pt 以上空ける）。内側の帯のツールバーの位置は未計測（近似）
- 実測値（Xcode 27.1 シミュレータ）：外側 466×678 pt @3x、安全領域 右 84 pt・下 34 pt、横 compact・縦 regular。内側（開いた状態） 951×669 pt @3x、安全領域 右 84 pt・下 34 pt、横 regular・縦 regular。タブバーと戻るボタンは両方の画面で右側の縦の帯に並んだ
- 文言の管理：String Catalogs（`Localizable.xcstrings`）
- アプリアイコン：この設計の範囲外（`design/icon/` で fresnel により作成済み）

### ナビゲーション（iPhone Duo）

| | 外側（466×678） | 内側・横（951×669） | 内側・縦（669×951） |
|---|---|---|---|
| 最上位 | タブバー（宛先 person.2.fill／レイアウト envelope.fill／設定 gearshape.fill）を**右端に縦**、下寄せ | タブバーを**右端に縦**、下寄せ（シミュレータの実測と同じ） | 通常の横向きのバー。幅 regular なので上部中央のカプセル（文字だけ） |
| ツールバー（記号のボタン） | 詳細の「編集」は文字ではなく記号（pencil）にする。文字のボタンは横向きのバーに残り、縦の帯に移らないため（HIG）。題名は VoiceOver とあふれメニュー用に残す |
| ツールバー | 右端の縦の帯の上から：カメラ → 時刻 → 戻る（chevron.backward）→ 主な操作（記号） | 一覧ペインの操作（サイドバー切替・…）は一覧ペインの上。詳細ペインの操作（編集・…）とステータスバーは右端に縦 | 上部に横並び |
| 階層 | 1段（一覧 → 詳細 → 戻る） | 一覧と詳細を並べる | 一覧と詳細を並べる |
| 一時的な作業 | シート。シートのボタン（キャンセル xmark・保存 checkmark）も右端に縦 | 中央のシート（横向きのバー） | 同左 |

- 下部の主要操作（`BottomActionBar`）：幅 compact（外側）は画面幅いっぱいに並べ、幅 regular（内側）はラベルの幅で後端に寄せる。こうすると内側の中央（折り目）にボタンがかからない
- 外側・内側で階層は同じ。機能を特定の姿勢に結び付けない
- **縦の帯があふれたとき**（ライブアクティビティなどで場所が足りないとき）に残す順：戻る／閉じる → 主な操作（編集・保存）→ その他。収まらないものはシステムのあふれメニュー（…）に入る。独自のあふれメニューは作らない。タブバーは下寄せのまま残す（移動が中心の画面のため）
- **タブの表示**：縦の帯のタブは記号だけ（システムの表示）。内側の縦向きの上部のタブは文字だけ（幅 regular のシステムの表示）。どちらもアプリで変えない
- **内側で宛先を選んでいないとき**：詳細ペインに `ContentUnavailableView`「宛先を選んでください」（記号 person.2）を出す。グループが空のときは一覧ペインに外側と同じ空状態（3つの追加ボタン）を出す

### 文言の統一

- 二重印刷の警告は全画面で「2026年12月1日に印刷済みの宛先です」（日付は年まで書く）。幅が足りなければ「…に」の後で折り返す
- 編集シートのキーボード上のボタンは「次へ」「キーボードを閉じる」。保存はシートの checkmark だけ

### 流れと確認

- 編集シートに変更があるとき、キャンセル・下スワイプで閉じようとしたら破棄の確認を出す（アプリの既存仕様）
- 二重印刷：印刷済みの宛先はプレビューに警告を出す（印刷はできる）

## 4. iPhone Duo

| 項目 | 方針 |
|---|---|
| 外側 | 1段。操作は右端の縦の帯（実測の安全領域 84 pt）。下部の主要操作は帯の左に収める |
| 内側・横（完全に開いた状態） | 一覧ペイン 330 pt（詳細より狭く）、詳細ペイン |
| 内側・横（半分折った状態） | 一覧と詳細を折り目（x = 475.5）を境に均等。中央 ±13 pt に見出し・ボタン・宛名面を置かない。一覧（スクロールする内容）は折り目にかかってよい |
| 内側・縦 | 横向きのバー。一覧と詳細を並べ、宛名面は折り目（y = 475.5）より上に収める。見出しの下の行（件数・無料版の残り、連名）はそれぞれのペインの幅で折り返し、省略しない。一覧ペインと詳細ペインの間は 16 pt 以上空ける |
| 印刷プレビュー | 横：用紙を左、操作を右。半分折ると用紙は左半分、操作は右半分（机に立てて置いても用紙が見える） |
| Split View（内側の左右半分） | 幅 compact になるので外側と同じ1段の構成になる（サイズクラスで切り替え） |
| 開閉で引き継ぐもの | 表示中の画面、選択中の宛先、編集シートの入力内容、プレビューのページを保つ（開閉・半分折りで状態を失わない） |
| VoiceOver の順序 | システムの標準（ナビゲーションの要素が先）に任せ、アプリで並べ替えない。安全領域は左右・上下で非対称（右 84 pt・下 34 pt） |
| 外側の横向き | 描かない。iPhone は縦向き固定（ユーザー指示）。HIG は横向きの対応を推奨しているため、方針を変えるときはここを見直す（保留） |
| 位置の扱い | カメラ・ステータスバー・縦の帯・折り目の位置は**近似**（Apple は数値を公開していない）。帯の幅と下の安全領域はシミュレータの実測値 |
